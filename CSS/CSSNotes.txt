#CSS - Cascading Style Sheet
It is defined as the styling language that is used to style our web page. The CSS is also popularly used for responsiveness (Website or application looks similar to all device.).

#types of CSS / Ways to apply CSS!!
There are basically three types of CSS:

1. Inline CSS
2. External CSS
3. Internal CSS

 -> Inline CSS : This is written inside the line using style attribute.
 -> Internal CSS: You're using CSS inside html but with the help of <style>...</style> Tag.
 -> External CSS: It is used externally by creating a file with extension .css

#SELECTORS inside CSS
Selectors are used to select something....(that is tags). Here are the following types:

1. Basic Selectors:
Ex -- h1{
        background-color: red;
    }

2. Id Selectors
3. Class Selectors
4. Universal Selectors (*)

#Units in CSS
These are used to measure or set the size of the elements. like images, texts, and etc.

Example -- px(pixels), %(percentage), vh(view height), vw(view width), em, rem

colors in CSS
-> Hex Values = #000000, #ffffff, ...
-> RGB = rgb(0,0,0)
-> Normal Ways => purple, black, white...

->Positions in CSS
The position property in css allows you to move the objects / elements in the webpage. We have 5 possible values.

1. static - Is at rest.
2. relative - element relative to <body>. top, bottom, left, right.
3. absolute
4. Sticky
5. fixed
